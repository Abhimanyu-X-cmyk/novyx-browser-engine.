NOVYX Browser Engine — Progress

Project Goal

Build an independent browser engine and eventually use it in browsers for Windows and Android.

Current Stage

Early learning and prototyping in Python.

Completed Experiments

- Display raw HTML.
- Identify HTML tags using regular expressions.
- Extract text from simple HTML elements.
- Build a simplified element tree.
- Experiment with Python's "HTMLParser".
- Print page text in a basic text renderer.
- Experiment with simple CSS rules.
- Match basic CSS rules to elements.
- Demonstrate layout using fixed-size boxes.

Current Main File

"novyx.py"

Contains a simplified HTML document-tree prototype.

Known Limitations

- Not a complete HTML parser or browser DOM.
- CSS support is experimental.
- No real visual rendering engine yet.
- No browser window, networking, JavaScript engine, or security architecture yet.

Next Milestone

Add test cases for the document-tree prototype before expanding its features.

Development Rule

Preserve working versions. Test each new feature and document its limitations.
